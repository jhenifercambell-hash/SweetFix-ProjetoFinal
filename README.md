# 🍬 SweetFix — Doces que Libertam

> **Satisfaça sua vontade de doce com mais consciência, sabor e equilíbrio!**

## 📌 Sobre o projeto

O **SweetFix** é um protótipo de plataforma web desenvolvido com a proposta de apresentar alternativas de doces saudáveis, considerando as preferências e restrições alimentares dos usuários.

A ideia surgiu da vontade de oferecer uma experiência mais personalizada para pessoas que gostam de doces, mas procuram opções que se adequem melhor ao seu estilo de alimentação.

A plataforma reúne um catálogo de produtos, filtros alimentares e recursos interativos para facilitar a descoberta de opções.

## 🎯 Objetivo

Desenvolver uma interface digital intuitiva e interativa que ajude os usuários a conhecer alternativas de doces, considerando características como:

- Presença ou ausência de glúten;
- Quantidade de carboidratos;
- Presença de proteínas;
- Opções veganas;
- Produtos com ou sem açúcar.

O projeto também teve como objetivo explorar a aplicação de **Inteligência Artificial Generativa e Engenharia de Prompt** no processo de criação e prototipagem de soluções digitais.

## ✨ Funcionalidades

- **Catálogo de doces:** apresentação de diferentes opções de doces saudáveis.
- **Filtros alimentares:** possibilidade de explorar produtos de acordo com características e restrições alimentares.
- **Sistema de recomendação:** fluxo interativo para auxiliar na descoberta de doces compatíveis com as preferências selecionadas.
- **Chatbot interativo:** recurso de conversa para orientar o usuário sobre as opções disponíveis.
- **Questionário de avaliação:** espaço para registrar opiniões sobre os produtos.
- **Sugestões dos usuários:** área destinada ao envio de ideias e sugestões.
- **Frases motivacionais:** mensagens que variam durante a navegação.
- **Interface responsiva:** layout adaptado para celulares, tablets e computadores.
- **Conteúdo informativo:** apresentação do conceito da plataforma e orientações de utilização.

A identidade visual foi inspirada em elementos do universo de jogos e animações, utilizando uma paleta de cores marcante:

- `#2F2C2B`
- `#413726`
- `#79451D`
- `#D7621A`
- `#FD8D32`

A interface utiliza elementos visuais como efeitos holográficos, glassmorphism, animações e detalhes inspirados em ambientes digitais.

## 🤖 Aplicação da Inteligência Artificial

A Inteligência Artificial Generativa teve participação importante no desenvolvimento do SweetFix.

Por meio de prompts elaborados pela equipe, a ferramenta Claude AI auxiliou na criação e no aprimoramento de aspectos como:

- Estrutura e organização da página;
- Construção da interface visual;
- Geração de ideias e funcionalidades;
- Organização dos filtros alimentares;
- Concepção do chatbot;
- Desenvolvimento da experiência de recomendação.

A utilização da IA também permitiu explorar conceitos de Engenharia de Prompt e compreender como essas ferramentas podem auxiliar no desenvolvimento de protótipos.

**Importante:** o chatbot e os recursos de recomendação fazem parte do protótipo. Nesta versão, não existe integração com uma API externa de IA nem banco de dados em tempo real.

## 🚀 Como executar

1. Acesse o repositório do projeto.
2. Baixe ou extraia os arquivos disponibilizados.
3. Localize a pasta `1.site`.
4. Abra o arquivo `sweetfix_updated.html` em um navegador atualizado.

Não é necessário configurar um servidor ou banco de dados para visualizar a versão local do protótipo.
